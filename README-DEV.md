# Tendedero Dev — 本分支做了什么

这是基于 [alejandrobujan/tendedero](https://github.com/alejandrobujan/tendedero)（已同步到上游 **v1.8.1**）的个人二次开发版，分支 `top-center-hover`，共 36 个提交。它作为独立的 **Tendedero Dev** 构建（`app.tendedero.Tendedero.dev`），不会碰你正在用的原生 `/Applications/Tendedero.app`。

下面按「上游没有、这里加了或改了」的顺序列一遍。

## 一、触发方式：顶部中间「往上推」

- 热区是屏幕顶部正中间约 320 × 144 pt；指针进入后**继续向上**并到达屏幕最上沿，晾衣绳才落下（上游是停在菜单栏中间就落下）。
- 没有提示面板、没有拉链动画：动作完成即落下，同时播放一声**内置的闷响**（`Resources/sounds/wake-thump.mp3`，`AVAudioPlayer`，可用「声音」关掉）并触发一次触觉反馈。
- 空绳不触发；菜单栏其他位置（Apple 菜单、状态图标、时钟）不触发；可在设置里关掉整个触发方式。
- 原有快捷键（默认 `⌥⌘T`）、菜单「显示晾衣绳」、全屏 App 行为、空绳逻辑都保留。

## 二、绳上的图片

| 操作 | 行为 |
|:--|:--|
| 单击 | 快速预览；打开「单击即复制」后改为复制 |
| 双击 | 复制图片（PNG + 文件 URL） |
| 中键 | 取下指针下的图片 |
| `⌃⌥⌫` | 删除指针下的图片（快捷键可改） |
| 右键 | 保留原生菜单：复制、打开、快速查看、标记、在 Finder 中显示、保存到桌面、取下、移到废纸篓、清理左右两侧 |
| 长按 / 力度点按 | 原生 Markup / Quick Look |
| 拖拽 | 原生拖拽；拖进文件夹保留文件，拖进废纸篓删除 |
| **滚轮下拉 / 双指下滑** | 把指针下的图片**拿在手上**（见第三节） |

「取下 / 删除」沿用原生语义：托管目录里的图片进废纸篓，外部文件只从绳上取下、不删除。

## 三、拿在手上

指针停在某张图上，**滚轮往下滚 / 双指下滑**（方向按设备判定，不受「自然滚动」影响；累计超过 30 pt 才触发）——图片从绳上滑落，**一条连续的曲线**下滑并放大到屏幕中间（0.24 s，没有分段停顿），绳上留半透明痕迹。

| 操作 | 行为 |
|:--|:--|
| 拖动 | 移动位置 |
| 拖动四角 / 边，双指捏合，`⌘` + 滚轮 | 缩放（保持比例，`⌘`+滚轮以指针为中心） |
| 左上角「识别文字」按钮 | 打开/关闭 OCR：打开后淡淡高亮全部可识别文字，文字上拖动即可**逐字框选**，选中为蓝色；关闭时不读图、不高亮、不拦拖动 |
| `⌘C` | 有选中文字时复制文字，否则复制整张图 |
| `C`（指针在图内） | 复制整张图，**留在手上** |
| `C` + 双击 / `⌥` + 双击 | 复制并放回绳上 |
| 双击 | 放回绳上（沿原路飞回） |
| 滚轮向上 / 双指上滑 / `Esc` / 右上角按钮 | 放回绳上（`Esc` 先清掉文字选中） |
| `⌘W` | 放回绳上 |
| **按住不放**（默认 1.2 s，可在设置改 0.8 / 1.2 / 1.8） | 图片按**自身比例**缩成一张带白边的文件图标（整图，不裁剪、不拉伸），指针抓在它的右下角；松手前一直处于系统拖拽状态 |

按住时的手感细节：

- 进度圈**不会一按下就出现**：按住超过约 0.4 s 才出现，从 0 线性填满到设定时长；没有隐式动画，不会「闪一下再出现」；
- 手指轻微抖动（< 6 px）不会打断长按，只有真正的拖动才会取消；
- 长按后进入**系统文件拖拽**：拖到访达或别的 App 上会出现标准放置提示；
  - **放下成功** → 图片直接回到绳上（不再回到手上）；
  - **没放成**（放空处 / `Esc`）→ 恢复成原来的大图；
- 拿着的时候 `C` / `⌘C` 复制的是**文件本身**，右键可复制 / 分享 / 返回照片。

## 四、截图接管：默认开启 + 队列

macOS 默认把截图放桌面。本版默认**接管**这个动作：

- 启动时把系统截图位置（`location` / `location-screenshot` / `location-screenrecording`）指到 App 自己的目录，并关掉浮动缩略图，截图落盘即挂绳；
- 仍然落在桌面的截图会被**移入**队列（系统设置被别处改回、或用别的工具存的都算）；
- App 没运行时落在桌面的截图，下次启动时按上次退出时间一并收进队列；
- 目录是**队列**：新图进队，队满时最旧的出队（进废纸篓），容量跟随「绳上保留」；
- 退出 App 时把系统设置还回去，不留没人看管的目录。

可在设置里整体关掉。

## 五、设置窗口

托盘菜单被收窄，日常操作之外的东西都进了**设置窗口**（托盘 → 设置…）：

| 分组 | 内容 |
|:--|:--|
| 截图 | 接管截图、挂上复制的图片、同步 iPhone 截图、同时监视的文件夹（列出 / 显示 / 移除 / 添加）、打开截图目录 |
| 晾衣绳 | 顶部正中间触发、新内容短暂显示、全屏 App 上显示、声音、单击即复制、绳上保留（能放几张 / 25 / 50 / 100）、大小（小 / 中 / 大）、按住不放变成文件的时长 |
| 快捷键 | 显示晾衣绳、删除悬停的图片（各自可重新录制） |
| 通用 | 登录时打开、版本、检查更新 |

托盘只剩：显示/隐藏晾衣绳、全部取下、撤销、全部放回（有手上图片时）、设置…、退出。

## 六、iPhone 截图

设置里打开「同步 iPhone 截图」后，App 监视 iCloud Drive 的 `Tendedero` 文件夹（不存在会创建），手机端只需一次快捷指令自动化：截图时 → 存到 iCloud Drive/Tendedero。详见 [docs/CLI-AND-PHONE.md](docs/CLI-AND-PHONE.md)。

## 七、`tendedero` 命令行

随仓库构建的 `tendedero-cli` 通过 **spool 指针文件**把文件挂到运行中的 App 上：

```sh
swift build -c release --product tendedero-cli
tendedero hang ~/pic.png          # 挂一张
tendedero hang *.png              # 挂多张
tendedero hang --dir ~/Downloads  # 挂文件夹里的图片
tendedero list                    # 打印 spool 目录
```

指针文件里是原文件的绝对路径，App 读完即删；**原文件不移动、不复制**，取下也不会删除它。详见 [docs/CLI-AND-PHONE.md](docs/CLI-AND-PHONE.md)。

## 八、其它改动

- **缩略图解码不再占主线程**：相机/剪贴板/手机同步同时来图时，缩略图在串行后台队列里解码，顺序不变，绳子落下不再卡顿；
- iCloud 还没下载完的文件会边下载边重试（最多 5 次），不再一次读不到就丢掉；
- 动画整体提速：飞到绳上 0.34 s、拿到手上 0.24 s、绳子落下 0.32 s、收起 0.18 s；
- 上游 v1.8.1 的功能全部同步（⌘Z 撤销、固定图片、空格预览、Markup 覆屏、Share 菜单、服务菜单等），本分支只改动上面这些。

## 九、两个版本并存

| | 原生版 | 开发版 |
|:--|:--|:--|
| App | `/Applications/Tendedero.app` | `/Applications/Tendedero Dev.app` |
| Bundle ID | `app.tendedero.Tendedero` | `app.tendedero.Tendedero.dev` |
| 偏好 | `app.tendedero.Tendedero` | `app.tendedero.Tendedero.dev` |
| 截图目录 | `~/Library/Application Support/Tendedero/Screenshots` | `~/Library/Application Support/Tendedero Dev/Screenshots` |

> 两个都接管截图时会来回改系统设置，同一时间只开一个。

## 十、构建与安装

```sh
scripts/build-dev.sh                 # 构建 build/Tendedero Dev.app（通用二进制 + ad-hoc 签名）
cp -R "build/Tendedero Dev.app" /Applications/
open "/Applications/Tendedero Dev.app"
```

正式版构建仍是 `scripts/build-app.sh`。

## 十二、验证过的点（本轮开发实测）

- 队列：目录塞 15 张 → 启动后裁到 10 张，最早 5 张进废纸篓，其余挂绳；
- 桌面接管：运行中放入带截图标记的图 → 自动移入队列并挂绳；
- 关闭期间：退出后放一张到桌面 → 下次启动收编并挂绳；
- 唤醒音：日志确认加载 `wake-thump.mp3`（0.744 s）并实际播放；
- 拿在手上：帧序列连续（56×112 → … → 337×724 → 回弹 341×734 → 337×724），无分段；
- 长按：1.2 s 缩成 118×74 的小页（宽图按比例），指针在右下角内侧；拖动 1:1 跟随；`Esc` 精确恢复原尺寸；
- 拖拽：系统拖拽会话正常建立，我们自己的窗口 `alpha = 0` 让位，无重影；
- `⌘W`、`C`、`⌘C`、双击、`⌥` 双击均按上表工作；
- 设置窗口：界面四项分组完整渲染，开关写入即时生效（`inboxEnabled` 1→0→1）。
